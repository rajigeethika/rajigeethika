### 🔥 Featured Projects

#### 🤖 [Nexus AI: Hybrid Intelligence Chatbot](https://github.com/rajigeethika/Hybrid-Chatbot-System)
A production-ready chatbot architecture that acts as a bridge between rigid retrieval-based systems and unpredictable Large Language Models. 
- **Built with:** PyTorch, Flask, Gemini API, NLTK, Vanilla JS.
- **Key Features:** Custom OOV (Out-Of-Vocabulary) anti-hallucination heuristic, live weather API integrations, and an SQLite-powered admin analytics dashboard.

#### 🛡️ [Data Redundancy Removal System (DRRS)](https://github.com/rajigeethika/Data-Redundancy-System)
An enterprise-grade data engineering pipeline that acts as a middle-layer between raw data ingestion and permanent storage to prevent database bloat.
- **Built with:** Python, FastAPI, SQLite, Chart.js, thefuzz.
- **Key Features:** Regex normalization, O(1) exact-match cryptographic hashing (SHA-256), O(N) NLP fuzzy-matching for near-duplicates, and an algorithmic performance-benchmarking dashboard.
